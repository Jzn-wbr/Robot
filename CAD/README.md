# Fichiers CAO

Ce dossier accueille les fichiers mécaniques du robot et leurs exports de fabrication.

Formats recommandés :

- fichiers source : `.f3d`, `.FCStd` ;
- échange : `.step` / `.stp` ;
- fabrication : `.stl`.

La vue d'assemblage actuellement disponible se trouve dans [`../images/assemblage_v1.png`](../images/assemblage_v1.png). Les fichiers CAO natifs restent à ajouter.
